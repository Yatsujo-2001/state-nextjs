# KUSATSU Vacation rental PJ — D1 建具製作図

| ファイル | 内容 |
|---|---|
| `KUSATSU_D1_VW.txt` / `.py` | **Vectorworks 用スクリプト**（同一内容。英数字のみで文字化けしない）。実行するとレイヤ縮尺どおりの図面を作図する（下記） |
| `D1_建具製作図.pdf` | A3横・ベクターPDF（S=1/5・1/15） |
| `D1_建具製作図.svg` | PDFと同一内容のSVG（PDFはこのSVGから出力） |
| `D1_建具製作図.dxf` | DXF（R2018）。**A3用紙座標（1単位＝用紙上1mm）のため実寸ではない** |
| `D1_確認事項一覧.md` | 未確定寸法・仕様の確認事項、算定根拠、整合性チェック結果 |
| `src/` | 作図・生成・検証スクリプト |

## Vectorworks（.vwx）の作り方（リソースマネージャから実行）

1. Vectorworks で新規ファイルを作成（単位 mm、原点・用紙位置は初期状態のまま）
2. **ファイル > 用紙設定** で A3・横
3. **ウインドウ > パレット > リソースマネージャ** を開く
4. リソースマネージャの **新規リソース** →「スクリプト」を選んで **作成**
   → スクリプトパレットの名前（例：D1）→ スクリプトの名前（例：D1作図）
5. スクリプトエディタで **言語を「Python Script」** にし、`KUSATSU_D1_VW.txt` をメモ帳で開いて
   全選択（Ctrl+A）→ コピー（Ctrl+C）→ エディタに貼り付け → **OK**
6. スクリプトパレットの「D1作図」を **ダブルクリック（1回だけ）**
7. 完了ダイアログで「作成 608 / 失敗 0」を確認
8. **表示 > レイヤオプション > 表示/スナップ/編集** にする
9. **ファイル > 別名で保存** で `.vwx` として保存

### 貼り付けがうまくいかない場合（代替）
`KUSATSU_D1_VW.txt` をデスクトップに置き、手順5で本文の代わりに次の数行を貼り付けて実行する。

```python
import os, vs
h = os.path.expanduser('~')
c = [os.path.join(h, d, 'KUSATSU_D1_VW.txt') for d in ('Desktop', 'Downloads', 'OneDrive\\Desktop', 'OneDrive\\デスクトップ')]
c = [p for p in c if os.path.exists(p)]
if c:
    exec(compile(open(c[0], 'rb').read().decode('ascii'), c[0], 'exec'))
else:
    vs.AlrtDialog('KUSATSU_D1_VW.txt をデスクトップに置いてください')
```

作成されるデザインレイヤ（図形はすべて実寸 mm で作図。例：KITCHEN面の扉は 680×2367）

| デザインレイヤ | 縮尺 | 内容 |
|---|---|---|
| 00_図枠・表題_1-1 | 1:1 | 図枠・タイトル欄・仕様表・特記 |
| 01_平面詳細図_1-5 | 1:5 | 平面詳細図 |
| 02_KITCHEN側正面図_1-15 | 1:15 | KITCHEN側正面図 |
| 03_TOILET側正面図_1-15 | 1:15 | TOILET側正面図 |
| 04_断面詳細図_1-15 | 1:15 | 断面詳細図 |
| 05_上部詳細図_1-5 | 1:5 | A：上部詳細 |
| 06_下部詳細図_1-5 | 1:5 | B：下部詳細 |

- クラス：D1-外形線／D1-細線／D1-寸法／D1-文字／D1-注記／D1-金物／D1-木目／D1-図名／D1-図枠／D1-ハッチ
- 文字はポイント指定（用紙上の大きさ）、線の太さはミル指定のため、どのレイヤでも PDF と同じ見え方になる
- 破線・ハッチは短い線分のグループ、寸法は線・点・文字で作図している（Vectorworks の線種リソース・寸法オブジェクトは使っていない）
- 実行後、作成数・失敗数・単位・用紙サイズがダイアログに表示される
- 2回実行すると図形が二重にできるので、やり直す場合は新規ファイルで実行する

## 再出力（寸法を変えた場合）

```bash
cd src
python3 d1.py out                          # out.svg / out.dxf（寸法の値は d1.py 冒頭の定数）
./render.sh out                            # out.pdf（Chromium で A3 印刷）
python3 check.py                           # 図面の整合性チェック
python3 vwgen.py ../KUSATSU_D1_VW.py        # Vectorworks 用スクリプトを再生成（.txt も同内容でコピー）
python3 test_vw.py ../KUSATSU_D1_VW.py      # 模擬 vs モジュールでスクリプトを検証（縮尺・実寸・配置）
```

必要なもの：Python 3、`ezdxf`、Chromium、IPAゴシックフォント。
