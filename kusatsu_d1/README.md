# KUSATSU Vacation rental PJ — D1 建具製作図

| ファイル | 内容 |
|---|---|
| `D1_建具製作図_VW.py` | **Vectorworks 用スクリプト**。実行するとレイヤ縮尺どおりの図面を Vectorworks 上に作図する（下記） |
| `D1_建具製作図.pdf` | A3横・ベクターPDF（S=1/5・1/15） |
| `D1_建具製作図.svg` | PDFと同一内容のSVG（PDFはこのSVGから出力） |
| `D1_建具製作図.dxf` | DXF（R2018）。**A3用紙座標（1単位＝用紙上1mm）のため実寸ではない** |
| `D1_確認事項一覧.md` | 未確定寸法・仕様の確認事項、算定根拠、整合性チェック結果 |
| `src/` | 作図・生成・検証スクリプト |

## Vectorworks（.vwx）の作り方

1. Vectorworks で新規ファイルを作成する（単位 mm、原点・用紙位置は初期状態のまま）
2. **ファイル > 用紙設定** で A3・横（420×297）にする
3. **ツール > スクリプト > スクリプトを実行…** で `D1_建具製作図_VW.py` を選ぶ
   （メニューが無い場合：リソースマネージャ > 新規リソース > スクリプト、言語を Python にして本文を貼り付け、実行）
4. **表示 > レイヤオプション > すべてのレイヤを表示**（または 表示/スナップ/編集）にする
5. **ファイル > 別名で保存** で `.vwx` として保存する

作成されるデザインレイヤ（図形はすべて実寸 mm で作図。例：KITCHEN面の扉は 680×2367）

| デザインレイヤ | 縮尺 | 内容 |
|---|---|---|
| 00_図枠・表題_1-1 | 1:1 | 図枠・タイトル欄・仕様表・特記 |
| 01_平面詳細図_1-5 | 1:5 | 平面詳細図 |
| 02_KITCHEN側正面図_1-15 | 1:15 | KITCHEN側正面図 |
| 03_TOILET側正面図_1-15 | 1:15 | TOILET側正面図 |
| 04_断面詳細図_1-15 | 1:15 | 断面詳細図 |
| 05_上部詳細図_1-5 | 1:5 | A：上部詳細 |
| 06_下部詳細図_1-5 | 1:5 | B：下部詳細 |

- クラス：D1-外形線／D1-細線／D1-寸法／D1-文字／D1-注記／D1-金物／D1-木目／D1-図名／D1-図枠／D1-ハッチ
- 文字はポイント指定（用紙上の大きさ）、線の太さはミル指定のため、どのレイヤでも PDF と同じ見え方になる
- 破線・ハッチは短い線分のグループ、寸法は線・点・文字で作図している（Vectorworks の線種リソース・寸法オブジェクトは使っていない）
- 実行後、作成数・失敗数・単位・用紙サイズがダイアログに表示される

## 再出力（寸法を変えた場合）

```bash
cd src
python3 d1.py out                          # out.svg / out.dxf（寸法の値は d1.py 冒頭の定数）
./render.sh out                            # out.pdf（Chromium で A3 印刷）
python3 check.py                           # 図面の整合性チェック
python3 vwgen.py ../D1_建具製作図_VW.py     # Vectorworks 用スクリプトを再生成
python3 test_vw.py ../D1_建具製作図_VW.py   # 模擬 vs モジュールでスクリプトを検証（縮尺・実寸・配置）
```

必要なもの：Python 3、`ezdxf`、Chromium、IPAゴシックフォント。
